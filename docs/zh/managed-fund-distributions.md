# ETF 与基金分配

*中文 · [English](../managed-fund-distributions.md)*

## 一、没交易 ≠ 没收入

这里最常见的失误，是从券商的交易记录推断：没买也没卖，所以没有可申报的。**持有一整年的 ETF，不管你碰不碰它都会派息。** 按季和按半年派息都很常见。

要看的是**现金变动**，不是交易。一个没有卖出记录、现金余额却在上升的券商账户，上升的部分就是分配收入。

从券商的交易历史里拉出整个财年，读入账行。它会给出付款日、每单位费率和持有单位数——足以精确确定收到的现金。

## 二、这不是股息

澳洲注册的 ETF 多为信托，且多数是 **AMIT（归属式管理投资信托）**。它们的分配是信托分配，不是公司股息。

最实际的判别法就是表格本身：股息那一节只有 unfranked、franked、franking credits 和 TFN withheld 四栏，**没有任何地方可以填境外收入和境外税收抵免**——而国际股票 ETF 的分配恰恰以这两项为主。收入无处可填，就说明进错了区。

要用 Managed fund and trust distributions 那一节。也**不要**另外勾选独立的「foreign income」类别：信托分配中的境外成分从信托那一节流过，两边都勾容易重复申报。

## 三、声明必须给到什么

年度税务声明（AMIT 的叫 **AMMA statement**）把分配拆成与申报栏位一一对应的成分：

| 声明上的行 | 填到 |
| --- | --- |
| Non-primary production income | 非初级生产收入栏 |
| Franked distributions / franking credits | 已完税分配与 franking credit 栏 |
| Other deductions | 分配相关扣除栏 |
| Net capital gain / total current year capital gains | 资本利得各栏，按方法拆分 |
| Assessable foreign source income | 应税境外收入栏 |
| Foreign income tax offset | 境外税收抵免栏 |
| Other income | 其他收入栏 |
| **AMIT cost base net amount（调增或调减）** | **无对应栏位 —— 归档** |

由此有两个推论。

**应税金额不等于现金。** 境外收入按**扣税前的毛额**申报，抵免另行主张。毛分配额 = 收到的现金 + 抵免额。只填现金数会同时低报收入、高报税负。

**cost base 调整永远不出现在申报表上。** 它调整的是你的成本，供将来卖出时计算资本利得用。弄丢这些声明，多年后那笔计算就无法还原。**每年归档一份，永久保存。**

## 四、时间陷阱

基金在财年结束后有三个月完成归属，而驱动预填的年度投资收益报告（AIIR）申报截止日是 **10 月 31 日——和自行申报的截止日同一天**。所以需要用预填的时候，分配数据往往还没到。

要据此安排：

- 主动向券商或登记处索取声明，不要干等预填；
- 券商平台的 statements 区可能只有账户与交易对账单，**没有税务声明**——托管模式下，基金的声明发给托管方，再由其另行转交；
- **查邮箱**：券商常会提前发一封说明声明何时送达的通知，这封信本身就是「你持有的是什么类型收入」的有力证据。

## 五、基金管理人公布的成分，可作兜底

基金管理人会在产品页公布当年的**每单位税务成分**估算。它不能替代你自己的声明——那是基金全年口径，年中买入的持有人成分构成不同——但有两个用处：

**交叉验证。** 声明到手后，拿成分结构与公布的百分比对照。差异过大说明其中一方有问题。

**有出处的兜底。** 如果确实无法在截止日前取得声明，把管理人公布的百分比套用到你**实际收到的现金**上，是一个有据可循的立场，远胜于漏报收入或凭空编一个拆分。记下出处与日期，先申报，声明到了再 amend。

还要注意：公布的表格在你的声明到达之前就能定下几件事——基金有没有分配过已完税收入、有没有资本利得、有没有可主张的境外税收抵免。

## 六、一个容易漏掉的细节

当分配同时包含**折扣法资本利得**和**境外税收抵免**时，抵免中可能有一部分对应资本利得，须按不同规则分摊。适用时声明会单独披露这一项。公开的每单位摘要通常**不做**这个拆分——所以用估算值时，正是在这一点上要标明为暂定。
